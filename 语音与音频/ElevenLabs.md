# ElevenLabs

> AI 语音合成独角兽，以逼真的多语言 TTS 与声音克隆技术成为语音赛道的标杆公司。

## 概述

ElevenLabs 成立于 2022 年，由前 Palantir 工程师 Piotr Dąbkowski 与前 Google 员工 Mati Staniszewski 创办，主打高保真文本转语音（TTS）、声音克隆与多语言配音。其产品线覆盖 TTS API、Dubbing（视频自动配音）、Conversational AI（实时语音 Agent）与 Reader App（文章朗读）。

在语音合成赛道，ElevenLabs 以「音质逼真 + 开发者友好 API」快速占领市场，客户涵盖出版、游戏、影视与客服行业，是评估语音生成技术演进的核心观察对象。

## 时间线

### 2025-01

- **2025-01** · [ElevenLabs 完成 1.8 亿美元 C 轮融资](https://elevenlabs.io/blog)
  由 a16z 与 ICONIQ Growth 领投，估值超 30 亿美元。资金用于研究语音基础模型与扩展 Conversational AI 平台，标志语音赛道进入平台化竞争阶段。

### 2024-11

- **2024-11** · Conversational AI 平台发布
  推出可构建实时语音 Agent 的完整平台，整合 ASR、LLM 编排与 TTS，将产品从「合成工具」扩展为「语音交互基础设施」。

### 2024-06

- **2024-06** · Reader App 上线
  面向消费者的朗读应用，可将任意文章、PDF 转为自然语音，是其从 API 服务向 C 端产品延伸的信号。

### 2024-01

- **2024-01** · [完成 8000 万美元 B 轮融资，成为独角兽](https://elevenlabs.io/blog)
  a16z、Nat Friedman 与 Daniel Gross 等参投，估值超 10 亿美元。同期发布 Dubbing Studio 与语音市场（Voice Library）。

### 2023-06

- **2023-06** · 完成 1900 万美元 A 轮融资
  发布 Eleven Multilingual v1，支持多语言语音合成，确立多语言配音的产品方向。

## 分析

1. **从工具到基础设施**：ElevenLabs 的演进路径（TTS API → 配音工作台 → 实时语音 Agent 平台）与 LLM 厂商的平台化路径高度同构，语音正在成为 Agent 交互的默认界面之一。

2. **护城河问题**：GPT-4o 原生语音、Google/Meta 的开源语音模型都在挤压独立语音公司的空间。ElevenLabs 押注的差异化是垂直深度（配音工作流、声音版权市场）与音质领先。

3. **伦理与滥用**：声音克隆被用于诈骗与深度伪造的案例频发，其安全策略（声音验证、水印）是行业监管讨论的样本。
