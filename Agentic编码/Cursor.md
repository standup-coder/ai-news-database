# Cursor

> AI 原生 IDE 的代表作，以最快速度达到 1 亿美元 ARR 的开发者工具，AI 编码商业化的标杆。

## 概述

Cursor 是 Anysphere 公司开发的 AI 原生代码编辑器（VS Code 分叉），核心体验包括 Tab 智能补全、Composer 多文件编辑与 Agent 模式。它把「模型能力 × 编辑器交互」打磨到极致，2024–2025 年间成为收入增长最快的开发者工具，也是 Anthropic/OpenAI 模型 API 的最大客户之一。

该线索追踪 Cursor 的产品演进、融资与 AI IDE 赛道竞争（对 GitHub Copilot、Windsurf、Claude Code 等）。

## 时间线

### 2025-06

- **2025-06** · 完成 9 亿美元 C 轮，估值约 99 亿美元
  Thrive、Accel、a16z 等参投，官方披露 ARR 超 5 亿美元，付费用户覆盖过半财富 500 强工程团队。

### 2025-01

- **2025-01** · Agent 模式成为主打
  Composer Agent 可自主完成多文件任务、运行终端命令、修复错误，Cursor 从「补全工具」转向「任务执行器」，与 Claude Code 正面交锋。

### 2024-12

- **2024-12** · 完成 1 亿美元 B 轮，估值 26 亿美元
  距上轮仅四个月，ARR 从千万级冲向亿级，被媒体称为「史上增长最快的 SaaS」。

### 2024-08

- **2024-08** · 完成 6000 万美元 A 轮，估值 4 亿美元
  a16z 领投、OpenAI 创业基金参投。同期 Cursor 在开发者社交圈病毒式传播，「AI IDE」品类被大众认知。

### 2023-10

- **2023-10** · OpenAI 创业基金种子轮投资
  Anysphere 获 800 万美元种子轮，产品定位「AI-first 代码编辑器」，早期以 GPT-4 驱动。

## 分析

1. **交互层的价值证明**：Cursor 不拥有模型，却靠交互创新（Tab 预测、上下文管理、Apply 机制）建立了体验壁垒——证明在模型商品化时代，「离开发者最近的一层」能捕获巨额价值。

2. **平台依赖的达摩克利斯之剑**：底层依赖 Anthropic/OpenAI 模型与 VS Code 生态，上游随时可能自竞（Claude Code、Copilot Agent）。Cursor 的应对是自研模型（Tab 补全模型、Composer 模型）逐步降低依赖。

3. **AI IDE 赛道的洗牌信号**：Windsurf 被 OpenAI 收购未遂后团队并入 Google（2025-07），赛道进入巨头收编阶段，独立公司的窗口期正在关闭。
