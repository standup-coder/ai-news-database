数据主权

你的数据，永远属于你

在云端服务盛行的时代，我们选择了一条不同的路。News4Coder 坚持本地优先， 让你的技术资讯数据完全掌握在自己手中。

完全本地存储

所有数据存储在本地 SQLite 数据库（~/.news4coder/），不依赖任何云端服务。没有账号注册，没有数据上传，你的阅读记录只属于你。

零云端依赖 SQLite

隐私优先设计

无需登录、无需授权、不收集任何遥测数据。你的阅读偏好、收藏文章、搜索历史，全部保存在本地，任何人都无法访问。

无需登录 零追踪

数据可导出

你的知识库随时可导出为 Markdown、JSON 或 CSV 格式。想备份？想迁移？想分享？一键搞定，数据自由流动。

Markdown 导出 开放格式

永久可用

不受服务商倒闭、账号被封、网络中断的影响。一次下载，终身使用。你的知识库可以陪伴你几十年。

核心特性

本地优先的智能工具链

从信息采集到知识沉淀，每个环节都在本地完成，既享受 AI 的便利，又拥有数据的掌控权

多源智能采集

直接调用 HN/Reddit/V2EX API + Jina AI Reader 网页提取，告别 RSS，实时获取高质量内容

LLM 内容增强

自动生成高质量中文摘要、技术标签、质量评分（0-10）和语言检测，快速筛选优质内容

智能策展

基于 LLM 质量评分和你的阅读偏好，自动生成「今日必读」清单，节省筛选时间

本地知识库

SQLite 持久化存储，支持全文检索 (FTS5)，构建属于你的技术知识资产，数据永远本地保存

RAG 问答

基于本地技术知识库回答你的问题，并标注引用来源。本地向量检索，无需上传数据到云端

断舍离支持

批量归档、自动清理、语义去重、订阅健康度报告——保持收件箱整洁，掌控信息摄入
