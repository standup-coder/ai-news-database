> 收录原则：宁可漏收，不可错收。一份标榜「人工筛选、保证质量」的库，错录一条幻觉比漏录一条真事件危害更大。

## 核验状态标记

- ⚠️ **存疑**：有来源但单一/二手，或细节自相矛盾
- ❓ **高度可疑**：规模离谱、增速极端，或仅见于预测/营销稿
- 🔍 **需一手源**：事件本身可能为真，但缺官方一手印证

## 一、商业/并购类（最易出幻觉，优先核验）

### SpaceX 与 xAI「合并」，合并体估值 1.25 万亿美元 — ❓
- 来源：Reuters、Guardian、CNBC（搜索摘要返回的 URL）
- 疑点：史上最大并购，规模极端。虽有主流媒体 URL，但 WSJ/FT 正文多次 403/超时无法逐一打开核验。合并理由含「天基数据中心」显得离奇。
- 核验建议：查 SEC EDGAR 是否有对应 8-K/代理书；查 SpaceX/xAI 官方博客。

### SpaceX「600 亿美元收购 Cursor/Anysphere」— ❓
- 来源：tech-insider.org、SpaceX S-1（SEC）提到与 Anysphere 的 compute and option agreement
- 疑点：史上最大初创收购，约 30× ARR。S-1 确实提到 Anysphere 协议，但「收购」vs「算力合作+期权」需区分。
- 核验建议：逐字读 SpaceX S-1 关于 Anysphere 的条款；查 Anysphere 官方声明。

### Anthropic ARR 470 亿美元（2026-05）反超 OpenAI — ❓
- 来源：VentureBeat、MLQ.ai、Saastr（二级媒体）
- 疑点：15 个月 80× 增速极端。可能与「booked revenue / run-rate / 含云分成」口径混淆。
- 核验建议：等 Anthropic S-1 路演公开披露的口径。

### xAI「全部 11 位联创离职」+ 80+ 研究员出走 — ⚠️
- 来源：The Next Web、Yahoo Finance、Fortune
- 疑点：与 SpaceX 合并事件强相关，若合并为假则此条亦存疑。但人才流失本身多家报道一致。

## 核验方法论

1. **优先一手源**：公司官方博客/新闻页、SEC 文件（8-K、S-1）、arXiv 论文、官方 GitHub release。
2. **≥2 家主流媒体交叉**：Reuters、Bloomberg、FT、WSJ、CNBC、TechCrunch、The Information、Ars Technica。
3. **警惕信号**：增速 >10×/年、金额为整数（如「600 亿」「1.25 万亿」）、仅见于聚合站/百科/Reddit、含科幻元素（天基数据中心）。
4. **中文媒体分级**：财联社/证券时报/澎湃/新华网一线 > 36氪/钛媒体/界面 > 百科/知乎/公众号。
5. 核验通过后，将条目从本文件移入对应线索与 `_2026大事记.md`，并在本文件标注「已核实入库（日期）」。
